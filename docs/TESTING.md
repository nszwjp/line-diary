# 動作確認

上から順に試し、✅ の結果になるか確認してください。うまくいかないときは、一番下の「困ったとき」を見てください。

## 1. テンプレート

| 操作 | 期待する結果 |
|---|---|
| リッチメニューの「テンプレ」を押す | ✅ 「どちらのテンプレートにしますか？」と返信が来て、下に「しっかり版」「ひとこと版」のボタンが出る |
| 「しっかり版」を押す | ✅ `📅 10/19（月）しっかり版` から始まるテンプレートが返ってくる（日付は今日） |

| スプレッドシートの `entries` シートを見る | ✅ ボタン操作は行として **増えていない** |

## 2. 日記の保存

| 操作 | 期待する結果 |
|---|---|
| テンプレートをコピーして書き込み、送信 | ✅ 「受け取りました」と返信が来る。`entries` に `type = text` の行が増える |
| 写真を1枚送る | ✅ 「受け取りました」が1回来る。`entries` に `type = image` の行が増え、ドライブの `LINE日記_写真` に原寸と `_thumb` の2ファイルができる |
| 写真を3枚まとめて選んで送る | ✅ 「受け取りました」は **1回だけ**。`entries` には3行増える |

## 困ったとき

### 何を送っても返信が来ない

1. **LINE Developers の Webhook「検証」が成功するか**
   失敗する場合は、Worker の URL と、Worker の `LINE_CHANNEL_SECRET` が合っているか確認
2. **Worker のログ**
   Cloudflare の Worker 画面 →「ログ」（または「Observability」）→「リアルタイムログを開始」してからメッセージを送る。
   `GAS responded: 200 {"ok":true}` 以外が出ていれば、そのメッセージが手がかりになる
   - `{"ok":false,"error":"unauthorized"}` → Worker の `GAS_SHARED_SECRET` と GAS の `SHARED_SECRET` が違う
   - HTML が返っている → `GAS_URL` が間違っているか、GAS のデプロイで「アクセスできるユーザー：全員」になっていない
3. **GAS の実行ログ**
   Apps Script エディタ左の **「実行数」** で `doPost` のエラーを確認
   - `スクリプトプロパティ ... が設定されていません` → 手順7・10の設定漏れ
   - `LINE API エラー 401` → `CHANNEL_ACCESS_TOKEN` が間違っている
4. `unknown_users` に自分の ID が増えている → `ALLOWED_USER_IDS` の ID が間違っている（余分な空白や1文字違いがないか確認）

### GAS のコードを直したのに反映されない

「デプロイを管理」で **新バージョン** を作る必要があります（SETUP.md の 5-3 の注意書きを参照）。

### 一覧ページが「読み込み中…」のまま、またはエラーになる

- `liff/config.js` の `LIFF_ID` と `API_URL` が正しいか、GitHub に push 済みか（反映まで数分かかることがあります）
- 「ログインの有効期限が切れました」→「再読み込み」を押す。直らない場合は `LIFF_CHANNEL_ID` が LINE **ログイン** チャネルの ID になっているか確認（Messaging API チャネルの ID ではありません）
- 友人だけ開けない → LINE ログインチャネルが「公開」になっているか（SETUP.md の 6-2）

### リッチメニューが出ない

- `createRichMenu` の実行ログにエラーがないか確認
- `RICHMENU_IMAGE_URL` をブラウザで開いて画像が表示されるか確認
- LINE のトーク画面をいったん閉じて開き直す
